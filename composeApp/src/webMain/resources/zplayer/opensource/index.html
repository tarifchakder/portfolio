Open Source Licenses

ZPlayer · Last updated: August 28, 2026

ZPlayer is built with the help of open source software. This page lists the third-party libraries bundled with the App, along with the license each one is distributed under. Tap any entry to read its full license text.

Some entries link to the license's canonical text instead of reproducing it in full, where the license itself is long (for example GPL, LGPL, and Apache 2.0).

Native Media Engine

ZPlayer's video and audio decoding is powered by an embedded build of FFmpeg.

    Licensed under the GNU Lesser General Public License v2.1 (or later). Some optional components are GPL-licensed and are not enabled in this build.

Source Availability

For libraries licensed under the LGPL or GPL, the corresponding source code (or a link to it) is available on request, and unmodified upstream source is publicly available from each project's own website linked above.
